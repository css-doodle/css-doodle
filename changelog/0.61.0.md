# 0.61.0

### Features

* Add `text` and `font` to shapes, tracing letters and emoji into outlines for `@shape`, `@plot` and `@tile`.
* Add `path` to shapes, reading SVG path data as outlines.
* Add `drag` to `@scene`, letting the pointer turn and tilt the view.
* Draw a `@pattern` inside `@doodle` or a texture block as a still image.

### Fixes

* Keep `@T` on the time of day, however late its animation started or long it was paused.
* Let `@cell` and `@random` read custom properties, as `@match` does.
* Keep a user function's expression body one value in `@pattern` and `@scene`.
* Fix scene variables after commands, and `sdf` and `intersect` surfaces.
* Speed up `@match`.
