# 0.59.0

### Features

* Define functions with `--name(params): body`, give parameters defaults with `name = value`, and call them with `$name(args)`.
* Add `@match(test) { }` in `@svg`.
* Let `@scene` fill read `normal`, the surface normal as the camera sees it.
* Lower live `&&`, `||` and `match` to CSS math.
* Read a bare name in `@svg` as an empty element.
* Add the `border` flag to `@grid`, shorthand for `ß 1px solid`, with `border:color` to set the color.

### Fixes

* Set `@svg` variables where they are written.
* Keep spaced arithmetic in `@arc` `r`.
* Keep `preserve-3d` on the container so the host background hides no cells in `p3d`.
* Treat `@shape: none` as no clip-path.
* Add `deg` to a bare `@grid` rotate angle after an axis.
* Read an arithmetic sequence count such as `@m(2+3-1, x)` as a number, not a range.
* Ignore extra arguments to `@calc`.
* Let a skipped user function argument take its default, and cap user function expansion.
* Keep GLSL variables out of `@shaders` texture sections.
* Fix hex literals, `**` nesting, `out vec4` and `u_mouse` in shaders, and `hsl()` in `@scene`.
* Drop disguised `javascript:` links in `@svg`.
* Restore the random stream when generating fails.
