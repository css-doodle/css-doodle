# 0.64.0

### Features

* Add `radians` and `degrees` to the math, and to what `@pattern` and `@scene` write out.
* Allow a function definition inside `@svg()`, in a block too, seen in that `@svg()` only.

### Fixes

* Take a difference below `1e-9` as none in comparisons, `sign` and `step`, so `.1 + .2 == .3` is `1` and `sin(π)` is `0`.
