# 0.63.0

### Features

* Call a user function by bare name in `$()`, `$px()` and `@match` tests.
* Weight picks with `xN`, and let `@P` skip every copy of the last pick.
* Join an `@svg` `g` into one path with `g|union`, `|subtract`, `|intersect` or `|exclude`.
* Add `currentTime`, seeking every clock of a doodle at once.
* Add `px` to `@pattern`, let it assign to a swizzle, and paint a later `fill` over the one before it.
* Run a value function's `match` block as values in `@scene`, which has no blocks.

### Fixes

* Read an unknown name in `@pattern` and `@scene` as `0`, so the shader still compiles.
* Trace a `polygon` or `lathe` outline for each copy when it reads `n`.
* Keep `@scene`'s ambient fixed to the world's up, and fit its view to shapes off the probe line.
* Compile `@scene`'s shaders faster, and redraw `@pattern` on every frame.
* Work out a random or picking argument once at the call when the body reuses or loops over it.
* Read `x (2)` as a call, and drop a live value where a number is required.
* Start nested doodles paused when their host was paused before it drew.
