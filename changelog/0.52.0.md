# 0.52.0

### Features

* Add `@udx` and `@udy` built-ins: cell center offset from the pointer.
* Add compact `@svg-filter` syntax with grouped operations, filter region options, and color matrix channel arithmetic.
* Add `@arc` helper for generating SVG arc path data (`M ... A ...`).
* Support depth on multi-cell grids (`3d` / `p3d`).
* Add `cond()` selector and function; unify conditional matching syntax with `match`.
* Support implicit multiplication in `@pattern` and math expressions.
* Add `safe` keyword to `@place` to drop unsafe overflow, and improve `@place` centering.
* Support paper presets in `@size` with aspect-ratio.
* Support `style` attributes, `animate` elements, easing, fill words, and `viewBox` shorthands in SVG.
* Export language surface metadata via `css-doodle/meta` subpath.
* Pause shader loops while the host is offscreen and add `role="img"` to host element.
* Support pausing/resuming animation clocks on nested doodles, SVG images, and pseudo-elements (`::before`, `::after`).
* Add formal language reference documentation (`docs/grammar.md`).

### Breaking Changes

* Make `@pn` and `@pnr` the canonical ordered pick functions.
* Remove legacy `ut` and `UT` aliases, and drop `β` symbol in favor of `ß`.
* Remove obsolete `@hover` selector.

### Performance & Internals

* Complete rewrite and modularization of CSS parser, generator, tokenizer, and component runtime.
* Index-based tokenizer scanning for significantly faster parsing.
* Compile value ASTs into evaluators and memoize parsed calc templates.
* Share WebGL contexts across matching raster sizes and deduplicate static style declarations.
* Switch build minification from Terser to SWC with tight bundle size optimizations.

### Fixes

* Fix image export readiness and suppress unwanted transitions during export.
* Fix GLSL transformations for vector fills, comparisons, pattern scoped variables, and Android highp precision.
* Fix negative number handling, viewBox computations, and draw durations in SVG generator.
* Fix calc negation precedence, cycle detection, and variable scope lookups.
* Fix Google fonts loading and embedding within exported images and SVG defs.
* Fix filter holder lookup on shadow root and prevent duplicate defs mounting.
