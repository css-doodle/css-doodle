# 0.53.1

### Changes

* Draw `random()` inside `$()` and `@calc` from a stream seeded by the doodle's seed, so a fixed seed now reproduces these values too.
* Read the sequence as the grid for `@R` inside `@m`, so one-column doodles no longer repeat a single value.
* Repeat nothing when a sequence count evaluates to `0`, without shifting later random values.
* Keep argument text as written in the `css-doodle/parser` AST (numbers come back as strings).

### Fixes

* Keep the drawing of a doodle that is moved in the document.
* Render sized nested doodles at the correct device pixel ratio in Safari.
* Resolve `@pattern` colors given in any color space, not only rgb.
* Apply `@direction` units after a space or a group.
* Report the line and column of generator warnings.
* Compile a failing shader once instead of on every restamp, and rebuild shaders after a lost WebGL context.
* Fix GLSL swizzles on digit-named variables, exponent literals, and chained swizzle types.
* Fix `click:cell` on 3D grids, unquoted keywords and functions in `content`, and negative SMIL delays.
* Fix calc with `- -1`, hex literals, and `<` inside parentheses.
* Fix SVG path commands glued together (e.g. `zm`) and escaped spaces in strings.
* Stop capping ranges at the grid limit, and fix code-point ranges.

### Performance & Internals

* Skip the id lookup for freshly generated inline SVG defs, which made large SVGs quadratic.
* Pass the `@pattern` fragment to the shader without parsing it again.
