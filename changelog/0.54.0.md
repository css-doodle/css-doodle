# 0.54.0

### Features

* Add `prerender()` to `css-doodle/generator`: render a doodle to HTML with a declarative shadow root that paints without the runtime.
  * Without a seed, the seed comes from the source, so every build renders the same picture.
  * Load transitions play through `@starting-style`.
  * Doodles on the same page that use different variables get separate filter ids.
  * The output escapes `</style` and stray `</template>` tags so they can't close the style element or the shadow root.
* Pause doodles when the user prefers reduced motion. A manual `pause()`/`resume()` overrides this, and the `ignore-reduced-motion` attribute turns it off.
* `@arc` continues the current path, so a second arc can close a ring segment.

### Changes

* Encode nested doodle images as escaped text instead of base64, so deeply nested doodles produce much smaller sheets.
* Print a group at-rule such as `@media` once per prelude, with its cell rules laid out the same way as top-level rules.
* Share the size of placed cells in one rule, and write the `@place` output without whitespace.

### Fixes

* Frame sized nested doodles so Safari scales them and keeps them animated, instead of drawing a png.
* Keep the random values of nested doodles across pause and resume.
* Split `]]>` inside CDATA sections so text containing it can't end them early.
* Give a unitless zero in `@place` a unit so `calc()` stays valid.

### Internals

* Use 2D-only Perlin noise for `@rn` and simplify the SVG tag tree and the tokenizer.
