# 0.53.0

### Features

* Add `@plot.scatter()` and `@Plot.scatter()`: spread points inside a shape's outline instead of along it, with `points` setting the count.
* Plot shape presets along their outline, one point per cell.

### Internals

* Build the uniform key list once per compiled function.
* Read exported variables straight from `getComputedStyle` and trim the font helpers.
* Simplify the SVG generators, the smaller parsers, and core helpers.
