# 0.62.0

### Features

* Let `$()` read the cell variables and bind user function parameters.
* Let `@pick(k: …)` fill `...` and pick from the list a lone item gives, as `@p` does.
* Let `@scene` `polygon` and `lathe` take `text` and `path`.

### Fixes

* Keep `@scene`'s perspective, and the dragged view on click, when dragged.
* Trace `text` again once its font loads, and quote bare font families.
* Keep a huge `@pick(k: …)` index on an item instead of throwing.
