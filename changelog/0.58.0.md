# 0.58.0

### Features

* Add `@scene` for 3D models, raymarched in WebGL.
* Add `union`, `subtract`, `intersect` and `exclude` groups to `@shape`.
* Name a shape with `name#id` and reuse it with `#id`, and repeat one with `name*N`.
* Add the `cross` and `leaf` presets.
* Continue a list after `...`, as in `@p(1, 3, ..., 11)`.
* Give `@tile.r` for every kind.
* Add `image()` to `css-doodle/generator`.

### Breaking Changes

* `@shape` now shares the shape language of `@scene`: `y` points up, `rotate` turns counterclockwise, and steps run in the order written.
* `frame` and `round` are lengths, not fractions.
* Rename `edge` to `grow`, `fill` to `fill-rule`, and `@tile.kind` to `@tile.k`.
* Remove the `bicorn` preset.
* A `seed` attribute restarts the random stream after the top-level pass, as `@seed` does.

### Changes

* Drop scripts, event handlers and `javascript:` links from `@svg`.
* Limit group sizes, nested sequences and `op:` steps.

### Fixes

* Fix `@place` inside `@keyframes`.
* Pass a whole list through `$name`.
* Keep spaces around `[`, `]` and `:` in grid line names and selectors.
* Fix `@svg` and `@doodle` in `@content`, and several parsing edge cases.
