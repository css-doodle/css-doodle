# 0.67.1

### Fixes

* Keep raw markup in `@svg` `content:` as written.
* Drop unsafe tags and `javascript:` links from `@svg`.
* Read `asin`, `acos` and `atan2` as radians in `$()`.
* Read `>` inside an `@svg` copy count as a comparison.
* Warn when code overflows the stack.
* Stop long numbers and names from hanging the parse.
