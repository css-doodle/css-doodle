# 0.70.0

I replaced the `@linearGradient` and `@radialGradient` with `stops` in each gradient block. The implementation is simpler and costs less code.

```css
/* Before */
fill: @linearGradient(red, gold .3, blue);

/* Now it's just a linearGradient block with stops */
fill: linearGradient {
  stops: red, gold .3, blue
}
```

### Breaking changes

* Remove `@linearGradient` and `@radialGradient`; write a `linearGradient` block with `stops:` instead.
* Remove `crack` and `stretch` from `@tile.voronoi`.
* Remove the `@PL`, `@PR`, `@pick-n` and `@pick-d` aliases of `@PN`, `@PNR`, `@pn` and `@pd`.
* Drop `÷`, `∧` and `∨` from `$()`.
* Read `^` as power in `@pattern` and `@scene`, as in `$()`, and give `%` the sign of the left operand; `mod()` stays floored.
* Read only `fill-rule`, not `fill`, as the fill rule of `@shape`.
* Give each whole number of `@ri` the same share and let a letter range of `@r` reach its last letter, so the same seed can draw other values.

### Features

* Add `stops:` to write the stops of an `@svg` gradient, as in `stops: red, gold .3, blue`.
* Add a key to `@r` and `@ri`: `@r(@i: 10, 50)` is one number per cell, the same wherever it is read.
* Read `and`, `or`, `not` and chained comparisons like `0 < x < 1` in `$()`.
* Name the random function of `@pattern` and `@scene` `random()`, keeping `rand()`.
* Add `eye` and `look` to place the camera in `@scene`.
* Take how wide the light is as a second value of `shadow` in `@scene`, as in `shadow: 1 .5`.
* Read a bare parameter in the arguments of a user function call as `$p`, as in `--row(k): $seg(k + 1)`.
* Draw several ranges in one `@arc`, as in `@arc(10, 0 to 90, 180 to 270)`.
* Start a new subpath with a bare `m` before `@arc` too.
* Chain `@arc` in the `path` of `animateMotion` and `textPath`.
* Let the browser skip the cells of a doodle while it is out of view.

### Fixes

* Read `@calc` as `$()`, with the cell's variables.
* Draw `@random(a, b)` in a value from its range, as `@r` does.
* Run a `:doodle(…) &` selector for each cell.
* Draw the random cells of each alternative in a selector list separately.
* Keep `@tile` inside `@svg` to its copies, so the cells stay in place.
* Keep the starting tile size when a tiling cannot come down to the pieces asked for.
* Keep the corner where a closed shape starts at the end of a `draw:` that stays.
* End a user function body inside `@svg` at the `}` of its block.
* Expand the calls in the defaults of a value function, and keep the names its calls assign its own.
* Let a function named `g` work in `@pattern`.
* Give every arm of `match()` the vector type when one arm is a vector.
* Keep the `//` of a URL out of line comments in `@pattern` and `@shaders`.
* Keep the line break after a `#` line just before a closing brace in `@shaders`.
* Keep `@t` in step on the page elements of `cells`.
* Keep the styles of a `cells` doodle out of its code.
* Wait for a detached doodle to load again before an attribute change redraws it.
* Speed up picks, `nth` selectors, `@random`, `@svg-filter`, lattice tiles and `$()`.
