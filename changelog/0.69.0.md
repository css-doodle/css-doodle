# 0.69.0

### Features

* Add `loading="lazy"` to draw a doodle only when it nears the viewport.
* Add `at` and a short form to `@arc`, as in `@arc(40 at 50 50, 0 to 120)`.
* Start a new subpath with a bare `M` before `@arc`.
* Give `@shape` and `@tile` plain numbers inside `@svg`, and add `@Plot` for plain points.
* Let `points:` read straight path data.

### Fixes

* Start `@t` over on `update()`.
* Let `random(a, b, …)` follow the doodle's seed, in `@tile` too.
* Read a variable's value as CSS in `$name`, so `3 -2` stays two numbers.
* Read a list in math as its first value, so `2 * 3 4` is `6`.
* Make `$(a)px` valid CSS for a live variable.
* Write live variables in full in `@grid` and `@gap`.
* Give the pseudo-elements of `:doodle` only to the hosts of cells.
* Draw circle and two-part `@tile` pieces inside `@svg`.
* Read the shapes in `union`, `subtract` and `intersect` as the browser draws them.
* Drop an `@svg` tag the XML parser rejects, with a warning.
* Keep a word after an escaped line break on its own line.
* Share a WebGL surface past the browser's limit instead of losing the oldest.
* Speed up the styles of `cells`.
