# 0.57.0

### Features

* Add `@tile.xy` to read the tile center as `x y`.
* Draw one `@shape` contour per item of a comma list.
* Allow expressions in `@shape`'s `points` and `rotate`, and reuse a shape kept in a variable.
* Support `@R.t` in `@tile`'s `edge:` and `slide:`.
* Add a base color to `@palette`, e.g. `@palette(5, tomato)`.

### Changes

* Keep `@palette` colors more distinct from each other.
* Default to `@place: center` and `@size: 100%` when `@tile` is used.
* Cap `@tile`'s `points` at the number of cells.
* Write rounded corners as CSS `shape()` curves.

### Fixes

* Fix `edge:` on a grid tile with `shift:`, and circle packing with a small `size:`.
