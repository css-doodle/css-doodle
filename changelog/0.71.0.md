# 0.71.0

A unit on a number in `$()` now stays a CSS unit, and the package ships TypeScript declarations.

### Changes

* Remove the `$p: value` write-back of value functions; give several results with `result: a, b` and read them with `a, b: $f()`.
* Bind `&` and `|` before a comparison, and `<`, `>`, `<=`, `>=` before `==` and `!=`, in `$()`, `@pattern` and `@scene`.
* Skip the body of a false `@match(test) { … }` in `@svg`, so the random values after it can change.
* Shape the saturation of `@palette` by hue, so seeded palettes draw other colors.

### Features

* Ship TypeScript declarations for the element and every export entry.
* Write a unit on a number in `$()` out as CSS: `$((@i - 4.5) * 12deg)` is `calc(-3.5 * 12deg)`.
* Read `rad` as radians in calls, as `deg` and `turn` are.

### Fixes

* Match every cell selector in a chain like `@row(1) @col(2)`, not just the first.
* Trace `text:` at its true weight; words came out too bold.
* Draw the first frame of a shader about a second sooner.
* Speed up text tracing and `union`, `subtract`, `intersect` and `exclude` groups of many shapes.
