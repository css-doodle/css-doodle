# 0.52.1

* Support dynamic counts in SVG repeats, e.g. `circle*@r(1, 5)` and range or calc forms.
* Expand `@svg-filter` in place inside an `@svg()` document instead of emitting a separate filter.
* Add a `seed` option to the exported SVG generator (`svg(rules, { seed })`).
* Thread the compiled seed and random state through embedded doodles, shaders, patterns, and textures, so a named seed draws the same picture everywhere.
* Fix SMIL animation timing in exported SVG images on Chrome, and keep SMIL offsets in sync while paused.
