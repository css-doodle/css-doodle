# 0.65.0

### Features

* Add `CSSDoodle.use()` to add an `@` function from outside the bundle.
* Load an addon by name with `@use: name`.
* Give a value addon `seed`, `color()`, `state`, `stream(key)` and `wait(promise)`.
* Add `@name.variant()` addons under an addon's own name.

### Fixes

* Keep the `0X` of a hex number as written.
