# 0.68.0

### Features

* Add the `cells` attribute to turn page elements into cells.
* Split the text of cells with `::letters` and `::words`.
* Add `@doodle.wrap` for seamless tiles.
* Add `bound: shape` to `@tile.voronoi`.
* Add `d` to `@tile`, the distance to the region's outline.
* Read colors like `oklch()` in `@pattern` and `@scene`.
* Let addons add `@doodle` variants.

### Fixes

* Read variables with underscores in `$()`.
* Fix density `x` and `y` after a shape's move or scale.
* Keep the parent's image variables out of nested doodles.
* Warn when a `//` line swallows the next statement.
