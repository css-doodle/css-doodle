# 0.67.0

### Breaking changes

* Remove Shadertoy support.
* Remove `@id` and `@hex`.
* Remove `@svg-pattern`, I barely use it.
* Write `@svg` boolean groups as bare `union`, `subtract`, `intersect` or `exclude` blocks, without the `g|`.

### Features

* Link shaders off the main thread and wait for them without blocking the page.
* Read `n`, `nx`, `ny` and `N` bare in `$()` inside a copy.
* Read `atan(y, x)` in `$()` as the angle of the point, as in GLSL.
* Take the `@tile` aspect from the size `@grid` gives the doodle.
* Let a negative gap overlap the cells of a cracked or stretched `@tile.voronoi`.

### Fixes

* Warn about a `var()` a color read cannot see instead of giving black.
* Overlap `@tile` pieces a hair when no gap is given, so no background shows where their edges meet.
* Move a lattice off center only when that fits half a row more pieces.
* Print `@tile` pieces and `@plot` points to a thousandth of a percent.
* Stop long digit runs and `a*` chains from hanging the number and loop checks.
* Escape `]]>` in `@svg` text, leaving raw CDATA sections alone.
