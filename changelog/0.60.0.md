# 0.60.0

### Features

* Define functions that return a value with `result:`, in `@pattern`, `@scene` and CSS values.
* Read function parameters bare in `@pattern` and `@scene`.
* Pick by a key with `@pick(k: a, b)`.
* Add `zoom`, `light`, `shadow` and `ambient` to `@scene`, and let `fill` read `light`.
* Add `mirror` to `@shape` steps.
* Add `plot.hex`, `plot.grid` and `plot.penrose`.
* Let a trailing comma stand for no argument, so `@match` keeps its else value.

### Fixes

* Pick, plot and sample noise per cell outside copies in `@scene`, like CSS.
* Animate `@scene` only when its code reads `t`.
* Size `@content` drawings after the sheet lands.
* Fix `$(pick(:))` and `random()` in `@shape` depending on earlier doodles.
